# Changelog

## 0.1.0 — developer preview

- Added native-surface playback on Linux with GStreamer and optional explicit mpv.
- Added native-surface playback on Android and Android TV with Media3 and optional explicit LibVLC.
- Added a typed headless controller, React player, track controls, CSS layout synchronization, visibility suspension, and playback telemetry.
- Kept buffering under the selected player by default, with optional backend-specific tuning.
- Added emulator and Linux qualification tooling.

Windows playback is not implemented.
