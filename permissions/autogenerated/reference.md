## Default Permission

Create and control bounded video sessions, inspect tracks, seek, and read sanitized playback statistics

#### This default permission set includes the following:

- `allow-runtime-capabilities`
- `allow-create-session`
- `allow-set-playback-state`
- `allow-seek`
- `allow-select-track`
- `allow-update-visibility`
- `allow-session-stats`
- `allow-destroy-session`
- `allow-native-open`
- `allow-native-control`
- `allow-native-layout`
- `allow-native-stats`
- `allow-native-close`
